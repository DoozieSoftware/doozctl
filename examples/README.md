# Examples

Runnable DoozCTL setups. Each directory is self-contained.

| Example | What it shows |
|---------|---------------|
| [hello-world](hello-world) | The smallest possible setup: one artifact. |
| [standards](standards) | A complete, copyable Standards Package (all strategies + summarize). |
| [brownfield](brownfield) | Merging into an existing repository with user content. |
| [generated](generated) | `replace-generated` and its overwrite safety rule. |

Requires a local build (`pnpm install && pnpm build`) or a global install of
`@dooziesoft/doozctl`.
