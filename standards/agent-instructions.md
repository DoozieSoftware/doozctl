## What is expected of an AI assistant?

<!-- DOOZCTL:BEGIN:v1 expectations -->

- Investigate before editing — inspect analysis, plan, workflow, callers and tests; never guess.
- Explicit gates are hard gates — every `## Required Evidence` item needs direct evidence (`doozctl verify`); file existence ≠ pass.
- Verification is part of work — targeted check → fix → regression → `doozctl doctor`/`verify` → final diff; never claim a command passed without executing it.
- Definition of Done: scope complete, acceptance met, evidence recorded, verification passed, diff reviewed, no blocker. Otherwise report PARTIAL/BLOCKED.
- Safety — no secrets in code, no destructive or cross-repo changes without confirmation.
- Keep artifacts minimal — plans readable in seconds, session summaries durable context only (<12 KB), execution over narration.

<!-- DOOZCTL:END:v1 expectations -->
