Architecture

Every command runs the same pipeline as a sequence of independent steps, in order, short-circuiting on the first failure.

Repository
↓
Analyze
↓
Load Standards
↓
Resolve Variables
↓
Render
↓
Merge
↓
Validate
↓
Persist

Layers

The CLI is thin: commander only parses arguments. A dispatcher routes each command to an application service, which selects its own pipeline. Read-only commands never reach write. Infrastructure enters through constructor injection — no DI container.

Three products

DoozCTL is really three things:

  • The engine — analyze, render, merge, sync. Nothing else.
  • Standards Packages — versioned packages that define repository artifacts.
  • Repository memory — the portable .ai/ convention.

Repository memory

    repository-analysis.json  factual repository metadata
