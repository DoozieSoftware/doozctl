Commands

Six commands. Every command supports --help.

doozctl init <repo> <package>

Analyze the repository, render the init-lifecycle artifacts, and write engine state.

doozctl sync <repo> <package>

Re-render managed artifacts from persisted repository state, preserving your edits.

doozctl analyze [repo]

Re-analyze the repository and update the repository memory (.ai/repository-analysis.json). Requires an initialized repository.

doozctl summarize <repo> <package> <session-file>

Append an immutable session summary and rewrite the current context.

doozctl doctor <repo> <package>

Verify the repository is initialized, the package loads, and artifacts are recorded.

doozctl status [repo]

Show what DoozCTL understands about the repository. Read-only.

Exit codes

Code Meaning
0 Success
1 Error (missing arguments, uninitialized repository, malformed state)

Session flags

summarize accepts optional metadata flags:

doozctl summarize . ./standards .ai/pending.md \
  --tool claude --model opus --user akshay
