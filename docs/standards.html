Standards Packages

A Standards Package is a plain directory. No packaging format, registry, or plugin system. 

standards/
    package.json
    artifacts/
    schemas/

The manifest is the only entry point. It declares the artifacts the engine renders:

{
  "format": 2,
  "name": "@dooziesoft/standards",
  "version": "1.0.0",
  "engine": ">=1.0.0",
  "artifacts": [
    {
      "id": "agents",
      "source": "artifacts/AGENTS.md",
      "destination": "AGENTS.md",
      "merge": "managed-blocks",
      "lifecycle": ["init", "sync"]
    }
  ]
}

Merge strategies

Strategy Behavior
overwrite Replace entirely
append Add after, never modify
replace-generated Replace only if the file carries the generated marker
managed-blocks Replace only inside marked regions, preserve everything else

The engine never invents behavior. All domain behavior lives in the package, never in the engine. See spec.md for the full frozen contract, and examples/standards for a copyable package.
