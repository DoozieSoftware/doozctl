Philosophy

Five values. No more.

Deterministic
Minimal

Deterministic

The same input always produces the same output. No timestamps, no ambient state, no ordering surprises. Repeated sync is byte-identical.

Minimal

Fewer moving parts is a feature. DoozCTL is a rendering engine, not an opinions framework. It does not define engineering practices.

Offline

Everything runs locally. DoozCTL never phones home and has no cloud dependency. Your repository is the source of truth.

Vendor neutral

DoozCTL does not know any AI vendor, language, or company convention. AGENTS.md is simply one artifact. Whatever the Standards Package declares is what gets rendered.

Repository first

The repository becomes the long-term memory. AI coding assistants become interchangeable execution engines — Cursor today, something else tomorrow.
