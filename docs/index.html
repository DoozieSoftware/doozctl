Repository Standards Engine

AI coding tools lose context. Repositories shouldn’t.

DoozCTL turns repository knowledge into persistent, deterministic artifacts that every AI assistant can share — Claude, Codex, Cursor, Gemini, OpenCode, and future tools. The repository becomes the long-term memory. Assistants become interchangeable engines. 

npm install -g @dooziesoft/doozctl
Get started GitHub

Install

Requires Node.js 20 or newer.

npm install -g @dooziesoft/doozctl

Initialize

Analyze a repository and render the artifacts a Standards Package declares.

doozctl init . ./standards

Synchronize

Re-render managed artifacts while preserving everything you wrote by hand.

doozctl sync . ./standards

Capture a session

Append an immutable session summary and rewrite the current context.

doozctl summarize . ./standards .ai/pending.md

Diagnose

Verify the repository is initialized and healthy.

doozctl doctor . ./standards

Status

See what DoozCTL understands about the repository.

doozctl status .
